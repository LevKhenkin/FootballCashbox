# Футбольная касса

Веб-приложение для сбора денег на оплату футбольных игр. Игроки вносят данные о своих
оплатах, админ ведёт игры, счёт от зала за месяц и общие траты. Цель — видеть, что по
каждой игре деньги собраны со всех участников.

## Возможности

Для игрока:

- список игр со стоимостью, долей с игрока, суммой сбора и личным долгом;
- внесение данных о своей оплате за конкретную игру (сумма подставляется из долга);
- страница «Мои оплаты»: история, подтверждённые и ожидающие суммы, текущие долги;
- карточка игры: кто сколько оплатил, у кого остался долг;
- сводка: по игрокам за месяц или по всем играм и по месяцам (зал + общие траты).

Для админа (через `/admin/`):

- игры: дата, место, стоимость, список участников;
- месяцы: сумма счёта за зал, закрытие месяца;
- общие траты (например, покупка мяча) с привязкой к месяцу;
- подтверждение или отклонение оплат игроков, в том числе массовыми действиями.

## Модель расчётов

- Доля игрока за игру = стоимость игры / число участников.
- В долг засчитываются только оплаты со статусом «Подтверждён».
- Нужно собрать за месяц = счёт зала + общие траты этого месяца.
- Баланс месяца = собранные подтверждённые оплаты − нужно собрать.

## Запуск

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

Приложение будет доступно на http://127.0.0.1:8000/, админка — на http://127.0.0.1:8000/admin/.

### Демо-данные

```bash
python manage.py seed_demo
```

Создаёт админа `admin`, игроков `ivan`, `petr`, `sergey`, `oleg` (пароль `football123`),
текущий месяц со счётом зала, две игры, часть оплат и трату на мяч.

## Тесты

```bash
python manage.py test
```

## Структура

- `tracker/models.py` — месяцы, игры, оплаты, общие траты и расчёты долей и долгов.
- `tracker/views.py` — страницы игрока: список игр, карточка игры, оплата, мои оплаты, сводка.
- `tracker/admin.py` — админ-интерфейс для игр, месяцев, трат и подтверждения оплат.
- `templates/` — шаблоны интерфейса.

## Замечания по эксплуатации

`football_funds/settings.py` содержит настройки для разработки: `DEBUG = True`,
`ALLOWED_HOSTS = ["*"]` и сгенерированный `SECRET_KEY` в коде. Перед публикацией в
интернете их нужно вынести в переменные окружения и выключить `DEBUG`.
